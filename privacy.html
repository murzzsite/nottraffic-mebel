Политика обработки персональных данных

Настоящая политика определяет порядок обработки персональных данных пользователей сайта Не только трафик.

1. Общие положения

Отправляя данные через форму на сайте, пользователь даёт согласие на обработку персональных данных (имя, телефон, название компании) в целях связи по вопросу оказания услуг.

2. Цели обработки

  • Связь с пользователем для консультации по услугам агентства
  • Подготовка коммерческого предложения и расчёта стоимости

3. Хранение данных

Данные передаются напрямую в мессенджер представителя агентства и не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

4. Права пользователя

Пользователь вправе запросить удаление своих данных, обратившись по контактам, указанным на сайте.
